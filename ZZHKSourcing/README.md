# ZZHKSourcing

一个用于展示岗位拆解、寻访策略、候选人评估和招聘进展的交互式工作台。项目基于招聘案例制作，支持招聘总览、岗位工作台和候选人详情等逐层查看。

## 功能

- 新增和编辑岗位、JD、筛选条件及候选人。
- 展示岗位搜索策略、筛选漏斗、候选人评分和推荐状态。
- 在候选人时间线记录跟进事件，并通过月历或年历查看工作活动分布。
- 将工作台数据保存在浏览器本地，并支持 JSON 导入和导出。

## 使用

保留项目文件，使用浏览器打开 `index.html`。网页采用静态 HTML、CSS 和 JavaScript，不需要构建步骤。浏览器本地数据不会自动跨设备或不同网址同步，迁移前请导出 JSON 备份。

## 数据说明

默认候选人、经历、评分、筛选漏斗及时间线均为模拟演示，不代表真实寻访或核验。Boolean 搜索式为拟采用策略，未实际运行。日历反映的是有记录的候选人活动，不能直接代表工作时长或招聘成效。

岗位描述中的企业名称已匿名化处理。项目由用户提出需求并审阅迭代，使用 Codex 辅助分析和开发。
