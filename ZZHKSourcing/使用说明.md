# 招聘工作台使用说明

打开本文件夹中的 `index.html` 即可使用。发布或迁移时，请保留本文件夹的完整内容及文件之间的相对路径。网页不依赖外部 CDN、在线字体、外部 API、OpenAI 服务或特定发布平台。

数据存于当前浏览器、当前访问来源的本地存储，不会自动跨设备同步。浏览器清理站点数据可能导致记录丢失。请定期通过页面右上角“导出数据”保存 JSON 备份。

迁移到新设备或新网址后，打开新地址，使用“导入数据”选择备份 JSON；导入将替换该浏览器当前工作台数据，操作前请先备份。`localhost`、本地文件与新网址属于不同访问来源，数据不会自动互通。

初始岗位与候选人、经历、资格及时间线为模拟演示。岗位来源和作业要求请以原始 Excel、PDF 及页面说明为准。日历不会读取 LinkedIn 活动。
